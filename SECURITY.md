# Security policy

## Reporting a vulnerability

Please do not open public issues for vulnerabilities, real credentials, session cookies, or personal data.

Use GitHub's private vulnerability reporting for this repository when available (repository owners can enable it under Settings → Advanced Security):
https://github.com/faroukpandor/OpenCast/security/advisories/new

If that form is unavailable, contact the repository owner through GitHub and request a private channel. Do not include exploit details in public profile comments.

## Supported scope

The `main` branch and the latest release commit are the intended support targets. This project is self-hosted; operators must configure HTTPS, proxy trust, backups, privacy contact, and source permissions for their deployment.

See `docs/SECURITY.md` for the implemented controls and explicit limitations.
